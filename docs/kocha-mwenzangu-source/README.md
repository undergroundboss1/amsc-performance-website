# Kocha Mwenzangu — source materials

Scholar-facing sources for the Coach Resource Hub (`/member-portal/kocha`).

| File | Used for |
|---|---|
| `AMSC_Kocha_Mwenzangu_Coach_Resource_Library.pdf` | Study cards, quick-reference cards and glossary were extracted once into `scripts/kocha/content.json`. The PDF itself is uploaded as the "full pack" download. |
| `AMSC_Kocha_Mwenzangu_Video_Shortlist.xlsx` | Imported into `kocha.videos` by `scripts/kocha/build_seed.py`, every row as `pending`. |
| `AMSC_Kocha_Mwenzangu_Baseline_Data_Sheet.xlsx` | Week 1 download (blank template, no athlete data). |

**Facilitator-only documents are deliberately not here.** This repository is
public, so the Online Classes facilitator guide, the Session 1 script and the
programme curriculum must never be committed, and are never uploaded to the
hub. Keep them in AMSC's private Drive.

The files in this folder are the source of record, not what scholars download:
course files are uploaded to the private `kocha` Storage bucket from the admin
portal (Kocha tab → Files) and served as short-lived signed links.
